PATCH CLOUDFLARE - TUM PASSAGEIRO WEB

1. Copie o arquivo wrangler.jsonc para a RAIZ do repositório passageiro-web,
   no mesmo nível do package.json.
2. Faça commit e push.
3. No Cloudflare, mantenha:
   Build command: npm run build
   Deploy command: npx wrangler deploy --assets ./dist
4. Rode o deploy novamente.

Este patch corrige:
- compatibility_date ausente
- nome do Worker diferente do esperado pelo CI
